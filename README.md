# YUANNotch

藏在 Mac 屏幕顶部的轻量工作台：随手记笔记、处理提醒、查看日程，或开始一轮专注。

本地优先，无需账户。支持 macOS 14+ · Apple Silicon。

## 界面导览

顶部切换页面；内容区随页面变化，面板可以拖出成为独立窗口。

| 页面 | 用途 | 数据位置 |
| --- | --- | --- |
| **Notes** | 多页 Markdown 笔记、图片、文件暂存 | 本地笔记目录 |
| **Reminders** | 切换列表、新建、编辑和完成提醒 | Apple 提醒事项 |
| **Schedule** | 按天查看日历与有日期提醒 | Apple 日历／提醒事项，只读 |
| **Goals** | 每日目标、番茄钟、历史时长 | 本地 Application Support |

## 核心功能

### 顶部常驻，随时展开

YUANNotch 常驻在屏幕顶部中央，通过悬停或点击即可打开；面板可以拖出成为独立的悬浮窗口，也可以双击或拖回顶部自动归位。支持多显示器，并可在设置中调整触发方式、响应延迟、外观和开机启动。

### 本地 Markdown 笔记

在 Notes 中快速创建和切换多个页面，内容以独立 Markdown 文件保存在本地。笔记目录可以指定为自己的文件夹或 Obsidian 仓库，粘贴的图片会保存到同目录的 `attachments` 文件夹，方便继续使用现有的文件工作流。

编辑器的标题标记、列表符号、任务框、引用、链接及编辑时可见的 Markdown 语法统一使用番茄钟的橙色，正文保留原色。列表采用紧凑缩进，圆点和任务框保持清晰可辨；同一级圆点与任务框共享水平中心，正文与换行使用统一起点。符号间距和嵌套缩进随笔记字号调整，不改写 Markdown 内容。

### Apple 提醒事项

在 Reminders 中直接切换提醒事项列表，创建、编辑、设置到期时间并完成提醒。数据由 macOS Reminders 管理；选择 iCloud 列表后，提醒会继续通过 Apple 的服务同步到其他设备。

### 日程与有日期提醒

Schedule 将 Apple 日历日程和有日期的未完成提醒放在同一个按天浏览的页面：进入时今天居中，左右滚动查看其他日期，两侧边缘渐隐。提醒只表示对应日期或到期时间，日历日程显示起止时间；无日期提醒仍在 Reminders 的列表中查看。

### 每日计划与番茄钟

在 Goals 中建立可重复的每日时长目标，为每个计划设置专属的专注与休息节奏。支持开始、暂停和切换计划，显示当前番茄轮次、当天累计进度，并保留历史完成记录；收起面板或切换到其他页面不会中断计时。

### 文件暂存区

将文件拖到顶部区域或展开的面板即可暂存，之后再拖到 Finder、其他应用或网页上传区域。暂存区支持排序和多选操作，只保存文件位置，不会移动、复制或删除原文件。

### 本地优先与可控的数据

YUANNotch 不要求账户，也不提供自有云端同步。笔记、图片、计划和计时状态保存在本机；提醒事项直接使用系统数据。你可以在设置中更改笔记目录，并单独启用或关闭文件暂存区和提醒事项集成。

## 如何使用

### 打开面板

默认情况下，把鼠标停在屏幕顶部中央即可展开 YUANNotch。也可以在 **设置 → Trigger** 中改为点击打开，并调整悬停触发的等待时间。

### 记录、提醒与每日计划

在 Notes 页面直接输入即可开始记录；使用左上方的 `+` 和 `−` 新建或移除笔记页面。切换到 Reminders 页面后，可以查看、创建和完成 Apple 提醒事项。第一次启用时，需要在 **设置 → Integrations** 中打开同步，并授予系统提醒事项权限。

Reminders 条目中的日期可以直接点击修改；无日期条目在悬停时显示日历按钮。日期编辑支持今天、明天、自选日期和可选时间，关闭 **Due date** 后保存可清除日期及提醒。保存后会更新 Apple 提醒事项，并同步调整本地列表的日期分组和排序；取消不会写入，保存失败则保留草稿供重试。

全天提醒按本地日历日期显示；带时区的定时提醒按其指定时区换算。夏令时切换日输入的时间按当地钟表时间解析，切换时区后保存已打开的 Goals 历史编辑不会改写相邻日期。

创建单次提醒时，可直接输入“28号晚上10点买药”“明天上午九点半开会”或“半小时后取快递”。输入框保留原文，日期和时间按钮显示识别结果，下方预览将保存的标题；回车或点击 Add 后创建。支持句首或句尾的常见中文日期、星期、中文数字及相对时间，省略月份的“28号”取最近一次有效日期。可以点击日期／时间按钮手动覆盖，或选择 **按原文** 保留完整文字。无效日期、已过时间、多个时间和重复表达会提示，不会悄悄创建；当前不支持重复提醒。相对时间在识别时确定为绝对时间，预览、创建与失败重试保持一致。

在 Goals 页面点击 **Add Daily Plan** 可以设置目标时长、启用日期和番茄钟节奏。点击计划右侧的播放按钮开始计时；Today 会把当前倒计时固定在计划列表上方，并显示当天整体与单项进度。专注阶段计入每日目标，休息阶段不计入。

点击计时卡片上的图钉，打开独立悬浮番茄钟。收起时为 **64 × 64 pt** 的深灰色方块，专注圆环为橙色，休息圆环为绿色；点击展开为 **350 × 125 pt** 的完整卡片，可开始／暂停、跳过当前阶段、重置或取消悬浮。

鼠标移出后，卡片短暂等待并连续缩回方块，不打断计时；重新悬停不会展开，仍需点击。等待或收缩中点击会立即恢复展开，这一击不会误触计时按钮。两种状态均可拖动；展开时按住圆环、倒计时或进度区域拖动，按钮保留点击功能。Goals 与悬浮窗中的橙色图钉均可关闭悬浮窗，计时保持原状。

悬浮番茄钟使用 macOS 原生窗口阴影，随圆角卡片的展开和收起更新，不再用手绘模糊轮廓模拟。

Goals 以本地时间每天 **04:00** 为新一天的起点，00:00–03:59 的专注仍计入上一日。到点后会结算上一日的专注时间、归零新一天的进度，并结束所有运行及暂停的计时，让全部计划回到收起的列表状态；不会自动开始新一轮。电脑睡眠或应用退出期间错过刷新，会在唤醒或下次启动后补做，计时只结算到错过的第一个 04:00。历史记录保留不清空，Today、启用日期和 History 使用同一日界线。

点击 Today 总进度旁的铅笔，或 History 中的历史日期，可以按计划修改当天的学习时长（小时和分钟）；额外的学习时间可填入 **Other focus**。保存后总时长、单项进度和历史日历同步更新，已删除计划的历史记录也可以修改。未修改的记录保留原有秒数，番茄钟保持当前节奏；连续计时按修正后的剩余目标更新倒计时，达到目标时结束。每日合计最多 24 小时，未来日期不可编辑。

### 查看日程

切换到 **Schedule**，点击 **Allow access** 授予 Apple 日历或提醒事项的读取权限；启动或浏览页面不会自动弹出授权请求。授权过程中显示 **Connecting…**，不会重复发起申请；成功后立即更新连接状态并重新读取来源。在系统设置中已经授予权限时，再次点击会直接连接并刷新，不再申请。日历和提醒事项分别授权，其中一个没有权限不会阻止另一个显示。拒绝后可从页面的 **Settings** 进入系统隐私设置。Reminders 与 Schedule 共用一个 EventKit 后台连接，避免两个连接对同一次授权保留不同的旧状态；不把授权结果写成本地永久权限记录。

右上方的来源按钮可选择需要展示的日历与提醒列表，**设置 → Integrations → Schedule** 也提供同一组选项。默认展示全部可读取来源，包括只读日历；选择会在重启后保留，全部取消即不显示该类来源，不会被自动恢复为全选。Schedule 的选择独立于 Reminders 当前选中的列表。

页面按当地自然日分栏，与 Goals 的 04:00 计时日界线分开。全天与跨日事件显示在各自覆盖的日期，结束时间为午夜的事件不会多占下一天；重复日程按每次发生的时间展示。左右滚动会继续加载其他日期，顶部箭头逐日移动，**Today** 返回今天。每列内容可独立上下滚动；每次切换到 Schedule，首帧就将今天居中，不会先显示其他日期再跳转。

日期列采用较紧凑的宽度，条目将时间与来源合并为一行并减少上下留白；其中提醒卡片使用更小的常规字重标题，并进一步压缩行距与上下留白，以显示更多内容，不改变日历事件、独立 Reminders 页面或全局字号设置。长标题仍可显示两行，悬停可查看完整信息。点击右上角刷新按钮时，使用与 Reminders 相同的图标旋转一圈，图标本身不会替换成进度控件。刷新期间保留现有条目、来源名称及已确认的空日期提示，新数据完成后再更新；自动刷新不播放手动刷新动画，首次加载或新浏览到的未读取日期仍显示加载状态。

Schedule 只读取系统数据，不创建、移动、完成或删除日程及提醒，也不另存一份独立日程数据库。页面可见时定期刷新，并响应系统数据变化、应用激活、唤醒和日期／时区变化。最窄的 Notes 工具栏会把 Tab 切换折叠成菜单，为笔记分页保留空间。

### 调整字号

在 **设置 → Appearance → Text** 中，界面字号可选择 Compact、Standard 或 Larger；Notes 与 Reminders 的内容字号独立设置为 **12–24 pt**，默认分别为 **15 pt** 和 **13 pt**。修改即时生效，重启后保留，面板尺寸仍由你自己调整。

| 快捷键 | Notes 正文编辑时 | Reminders 页面 |
| --- | --- | --- |
| **⌘+** / **⌘=** | 放大笔记正文 | 放大提醒标题、新建和编辑输入框 |
| **⌘−** | 缩小笔记正文 | 缩小提醒内容 |
| **⌘0** | 恢复 15 pt | 恢复 13 pt |

快捷键仅作用于当前页面所在的活动窗口，不改变 Markdown 或提醒文字，也不缩放工具栏、日期标签、Schedule 或设置界面。

### 使用暂存区

暂存区默认启用，但没有文件时不会一直占用面板空间。将文件拖到屏幕顶部的 YUANNotch 区域或已经展开的面板，暂存区会自动出现。之后可以把文件从暂存区直接拖入其他应用；有暂存内容时，也可以点击编辑区下方的托盘图标收起或重新展开。

如果暂存区已被关闭，可以前往 **设置 → File Shelf**，打开 **Enable file shelf**。

### 拖出浮动与自动归位

- **拖出浮动：** 按住面板底部中央的灰色短线，向下拖动，面板就会脱离屏幕顶部，成为可以自由移动的悬浮窗口。
- **自动归位：** 双击灰色短线，或者把悬浮窗口拖到屏幕顶部，面板都会自动吸附回原位。

## 下载

[下载最新版本](https://github.com/Hy0IU/YUANNotch/releases/latest)

目前支持 macOS 14 或更高版本，以及 Apple Silicon Mac。

优先下载 Release 中的 DMG 安装包，双击打开后，按窗口中的箭头将 YUANNotch 拖到右侧的 Applications（应用程序）图标。复制完成后，从“应用程序”打开 YUANNotch，再推出安装镜像。如果下载的是旧版本 ZIP，请解压后将应用拖入“应用程序”。

DMG 提供安装引导窗口；是否通过 macOS 安全检查还取决于应用签名和 Apple 公证。当前本地打包默认使用临时签名，不包含 Apple 公证。

## 数据与隐私

笔记以普通 Markdown 文件保存在本机，图片也存放在同一个笔记目录中。每日计划、计时状态和完成进度保存在应用的本地 Application Support 目录。提醒事项直接读写 macOS 的系统提醒数据库；Schedule 只读取所选日历与提醒列表，本地仅持久保存来源选择。YUANNotch 不提供自己的账户、云端或同步服务，也不会向 AI 服务发送这些内容。

## 从源码构建

需要 macOS 14+ 和 Swift 6：

```bash
git clone https://github.com/Hy0IU/YUANNotch.git
cd YUANNotch
bash Scripts/package-app.sh
```

日程的数据边界和界面可通过离屏探针验证，不需要操控桌面或弹出权限请求：

```bash
bash Scripts/schedule-probe.sh
bash Scripts/toolbar-layout-probe.sh
```

日程探针覆盖授权成功、已有授权重新连接、拒绝与撤销、申请中的重复点击，以及跨日、全天、夏令时、提醒日期投影、来源选择保存、部分读取失败与异步查询顺序；另验证手动刷新保留已有条目和空日期状态、后台刷新保持安静、新日期仍有加载提示，并输出同一页面刷新前、中、后的离屏采样。页面在不同宽度和字号下渲染。授权状态用隔离的数据源验证，不操作系统权限；仅在已有系统授权时额外执行只读查询，不记录条目正文。首次日历授权对话框仍需在打包应用内手动确认。

本次日期、阴影和字号行为也有独立探针：

```bash
bash Scripts/timezone-probe.sh
bash Scripts/floating-plan-probe.sh
bash Scripts/reminder-edit-probe.sh --font-ui
```

时区探针不修改系统时区；悬浮窗探针验证原生阴影配置和卡片轮廓，离屏图不包含 WindowServer 绘制的阴影。字号探针临时打开测试窗口，验证真实提醒输入框和快捷键，不读写个人提醒事项。

## 制作发布安装包

当前版本为 **1.0.2**，构建号为 **15**。发布脚本默认生成 DMG 和 SHA-256 校验文件，放在 `.release/`，不会替换 `/Applications` 中正在使用的应用。传入计划发布的版本号和递增构建号，例如：

```bash
bash Scripts/make-release.sh 1.0.2 15
```

DMG 内含应用、Applications 链接和安装引导背景，挂载时会请求 Finder 打开安装窗口。布局工具直接生成镜像元数据，不需要控制 Finder，也不需要安装额外依赖。脚本同时生成 `*-preview.png` 合成效果图，便于检查设计；它不是 Finder 实际截图。

如需同时保留 ZIP 下载，设置 `INCLUDE_ZIP=1`：

```bash
INCLUDE_ZIP=1 bash Scripts/make-release.sh 1.0.2 15
```

正式分发时，使用有效的 Developer ID Application 证书和已经配置好的 `notarytool` 钥匙串配置：

```bash
SIGN_IDENTITY='Developer ID Application: …' \
NOTARY_PROFILE='your-notary-profile' \
bash Scripts/make-release.sh 1.0.2 15
```

脚本会签名应用和 DMG，等待 Apple 公证、附加并验证公证票据，最后计算校验值；任一步骤失败都会停止。仅设置 `SIGN_IDENTITY` 不会自动公证。启用 ZIP 时，也会公证并附加 ZIP 内应用的票据。

发布前可校验压缩镜像、应用签名、Finder 布局、重新挂载后的背景引用和自动打开标记：

```bash
bash Scripts/dmg-probe.sh .release/YUANNotch-1.0.2.dmg
(cd .release && shasum -a 256 -c YUANNotch-1.0.2.dmg.sha256)
```

最后在目标 macOS 上双击 DMG，检查 Finder 实际显示和拖拽安装，再将 DMG 与校验文件上传到对应的 GitHub Release。
